MeowNotebook：把 cc 对话变成会渲染公式的本地笔记本

发表于2026-10-25|更新于2026-10-25|小工具
|总字数:1.3k|阅读时长:4分钟

每天在终端里和 cc（命令行 AI 编程助手）聊论文、推公式、写代码，聊完回头一看：公式是一串串 $\frac{\partial L}{\partial \theta}$，好不容易问明白的东西散落在几十个会话里，想找上周那段推导只能靠记忆。于是我做了 MeowNotebook —— 一个把 cc 对话变成本地笔记本网站的小工具。

仓库地址：MiaowFisherSpeaker/MeowNotebook，欢迎来玩、来提 issue、顺手点个 ⭐ 喵～

它能做什么

一句话：所有 cc 会话自动出现在一个网页里，按「问 → 答」排好，公式渲染好；网页底部就是那个 cc 的真实终端，可以直接接着聊。

📖 公式终于能看了

会话按目录分组放在侧栏，每一轮问答清清楚楚；中间那些过程文字和工具调用默认折叠，想看再展开。KaTeX、代码高亮、Markdown 表格全都本地渲染，断网也能用。

✎ 整理版：一键把对话变成笔记

在 cc 里敲一句 /qa-notes，它会把这次对话整理成结构化的笔记：去掉来回试错的过程，公式统一成 LaTeX，网页上切到「整理版」就能看。历史会话也能整理，网页上有现成的「复制 /qa-notes 命令」按钮。

✦ 总结：这周我都学了些什么？

侧栏「✦ 总结」里写一句要求，比如「只要论文相关的」或者「我开发 MeowNotebook 的进展」，选一天或一段时间，cc 就会把这期间的问答读一遍，写成一份带来源的总结。写周报、复盘学习进度都很顺手。

★ 收藏、🔍 搜索、📋 复制为 Markdown

  • 收藏：每个问题右上角一颗 ☆，存的是快照，原始记录删了也还在。
  • 搜索：标题 / 提问 / 全文三种范围，多个关键词同时命中才算，点结果直接跳到那一轮并高亮。
  • 复制为 Markdown：选中一段，右键「复制为 Markdown」，公式、表格、代码块都还原成源码，直接贴进自己的笔记。
  • 问题地图：问答左边一排小横条，鼠标移上去浮出附近几问，长对话里也不会迷路。

💻 网页底部就是真终端

这是我自己最喜欢的部分。cc 会把会话放进专门的 tmux 里，网页底部连的是同一个会话：两边画面、输入完全同步，只转发终端字节，不额外消耗 token。

  • 关网页、断 SSH、合上电脑，cc 都在后台继续跑；回来 cca 或者打开网页就能接上。
  • 网络不好时敲的键不会丢：每次输入都等服务器确认，断线重连后自动补发，也不会重复。
  • 终端里 /resume、/clear 换了会话，网页会自动跟过去。
  • 侧栏还有个只读的「文件」浏览器，Markdown（含公式）、代码、图片、PDF 都能预览；对话里出现的文件路径可以直接点开并定位到行。

🐧 彩蛋：在 QQ 里和 cc 聊天（可选）

配置一个 QQ 官方机器人，就能在 QQ 私聊里直接问 cc。QQ 里的对话也是普通的 cc 会话，侧栏会标上「QQ」，回到电脑前可以在网页上接着聊；整理版和总结也能「发送到 QQ」。配置过程甚至可以让 cc 自己带你做完。

三步上手

依赖只有 Python ≥ 3.8、tmux 和 cc 命令行。后端只用 Python 标准库，前端是原生 JS，第三方库全部放在仓库里，不需要 pip install，也不需要 npm install。

打开 http://localhost:8765 就能看到网站。在远程服务器上用的话，ssh -L 8765:localhost:8765 你的服务器 转发一下即可。

命令 作用
cc 在当前目录开一个新会话，网站自动启动
ccr 列出当前目录的历史会话，选一个继续
ccls 看看哪些会话正在运行
cca [名字] 回到某个会话
ccweb 只启动网站

隐私与安全

  • 所有数据只在本机：会话记录只读不改，整理稿、总结、收藏都存在仓库的 data/ 里（不进 git）。
  • 网站只监听 127.0.0.1，WebSocket / POST 要求同源并只认 localhost 主机名，防止别的网页或 DNS rebinding 连上你的终端。
  • ⚠️ 需要知道的一点：cc 以 bypass 模式运行，网站本质上是一个免密的终端。只在信任的目录里用，千万不要把 8765 端口暴露到公网。

写在最后

MeowNotebook 一开始只是想「把公式看清楚」，用着用着就长出了整理、总结、搜索、网页终端、QQ 机器人……它现在是我每天学习和写代码的主力工具。

如果你也常和命令行 AI 助手聊数学、聊论文，希望它也能帮到你。遇到问题或者有想要的功能，欢迎到 Issues 留言～ 🐾

注：MeowNotebook 是个人工具，与任何厂商无关。
